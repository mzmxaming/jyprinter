# Linux / 银河麒麟（Kylin V10 x86_64 / ARM64）、UOS、通用发行版运行时依赖
#
# 版本选择说明：
#   银河麒麟 V10 自带 Python 可能为 3.7（部分为 3.8），因此这里统一选用
#   「Python 3.7 亦可安装」的最后一批版本，保证源码模式在麒麟上开箱可用。
#   若目标机 Python ≥ 3.8，也可直接使用 requirements.txt（版本更新）。
#
# 安装（脚本会自动执行）：
#   python3 -m venv --system-site-packages .venv      # 需 --system-site-packages 才能用到系统 python3-gi（pystray 依赖）
#   .venv/bin/python -m pip install -r requirements-linux.txt
#
# 离线/内网环境安装：
#   在可联网机器上：  pip download -d wheels -r requirements-linux.txt
#   拷贝 wheels 目录到目标机后：pip install --no-index --find-links=wheels -r requirements-linux.txt
#
# 系统级依赖（pip 无法提供，由 install_linux.sh 安装）：
#   cups cups-client      —— 静默打印后端（lp / lpstat / lpoptions）
#   libreoffice           —— Office/WPS 文档转 PDF（缺失时仅影响 9 种办公格式）
#   fonts-noto-cjk        —— 中文渲染字体（缺失会拒绝打印并提示安装）
#   python3-tk            —— 图形配置对话框
#   python3-gi + gtk3     —— pystray 托盘后端（仅桌面自启模式需要）
#   network-manager       —— 网页/托盘内配置静态 IP（nmcli）
